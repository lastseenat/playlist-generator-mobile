# Playlist Generator Mobile

## Français

Dépôt officiel de téléchargement de **Playlist Generator Mobile** pour Android.

### Télécharger l’application

Téléchargez `playlist-generator-mobile-v1.0.apk` depuis la
[release v1.0.0](https://github.com/lastseenat/playlist-generator-mobile/releases/tag/v1.0.0),
puis ouvrez le fichier sur un appareil équipé d’Android 10 ou d’une version
ultérieure.

Playlist Generator crée des playlists à partir de votre bibliothèque musicale
et les ouvre dans Poweramp.

### Fichiers disponibles

- `playlist-generator-mobile-v1.0.apk` : application Android
- `playlist-generator-mobile-third-party-materials-v1.0.zip` : mentions et
  textes de licences des bibliothèques tierces

### Version Windows

La version Windows possède sa propre
[page de téléchargement](https://github.com/lastseenat/lastseentools/releases).

### Vérification

Comparez l’empreinte SHA-256 du fichier téléchargé avec celle affichée dans la
release.

## English

Official download repository for **Playlist Generator Mobile** on Android.

### Download the app

Download `playlist-generator-mobile-v1.0.apk` from the
[v1.0.0 release](https://github.com/lastseenat/playlist-generator-mobile/releases/tag/v1.0.0),
then open the file on a device running Android 10 or later.

Playlist Generator creates playlists from your music library and opens them in
Poweramp.

### Available files

- `playlist-generator-mobile-v1.0.apk`: Android application
- `playlist-generator-mobile-third-party-materials-v1.0.zip`: third-party
  notices and license texts

### Windows version

The Windows version has a separate
[download page](https://github.com/lastseenat/lastseentools/releases).

### Verification

Compare the SHA-256 checksum of the downloaded file with the checksum shown in
the release.
